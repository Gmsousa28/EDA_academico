# EDA_academico

## Resumo do Projeto
Este repositório contém um projeto académico focado no desenvolvimento de um sistema de gestão para uma rede de antenas, realizado no âmbito da disciplina de Estruturas de Dados e Algoritmos (EDA). O objetivo central foi aplicar conceitos de programação e algoritmos na estruturação e manipulação eficiente dos dados associados às antenas. O sistema foi implementado integralmente em linguagem C, com o código modularizado em diferentes ficheiros para separar a lógica de negócio das estruturas de dados e da interface principal.

## Tecnologias Utilizadas
* Linguagem C

## Estrutura do Projeto
O repositório está organizado com os seguintes ficheiros[cite: 2]:

* Projeto1.c: Contém a implementação das funções e a lógica principal responsável pela gestão do sistema de antenas[cite: 2].
* Projeto1.h: Ficheiro de cabeçalho (header) com as assinaturas das funções e a definição das estruturas de dados utilizadas para modelar as antenas[cite: 2].
* Projetomain1.c: Ficheiro que contém a função principal (`main`), servindo como ponto de entrada e interface de execução do programa[cite: 2].
* ExecutarFinal.exe: O executável final compilado, pronto a ser executado em ambientes Windows[cite: 2].
* Projeto_1_Final.zip: Arquivo compactado que contém a versão final e completa do projeto submetido[cite: 2].

## Compilação e Execução

Para executar o projeto, tem duas opções:

**Opção 1: Utilizar o executável (Apenas Windows)**
Basta fazer o download e executar diretamente o ficheiro `ExecutarFinal.exe`[cite: 2] presente no repositório.

**Opção 2: Compilar o código-fonte manualmente**
Para compilar o código utilizando o GCC, abra o terminal no diretório dos ficheiros e execute:

1. Compilar os ficheiros:
\`\`\`bash
gcc Projetomain1.c Projeto1.c -o ExecutarFinal
\`\`\`

2. Correr a aplicação compilada:
* No Windows:
\`\`\`bash
ExecutarFinal.exe
\`\`\`
* No Linux/macOS:
\`\`\`bash
./ExecutarFinal
\`\`\`
